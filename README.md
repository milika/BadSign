# Bad Sign

An iOS app by Void Software that shows your sign in 11 astrology and
numerology systems (Western, Chinese, Aztec, Mayan, Egyptian, Zoroastrian,
Celtic, Norse, Slavic, Numerology, Geek), plus a twelfth "Bad Sign" derived
from the rest, and your birthday's moon phase.

Objective-C, UIKit and WebKit, iOS 15+, iPhone, no dependencies.
[App Store](https://apps.apple.com/app/id912176242).

## Build

Open `Bad Sign.xcodeproj` in Xcode and run the `Bad Sign` scheme, or see
[docs/build-and-release.md](docs/build-and-release.md).
